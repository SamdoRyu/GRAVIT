# Fix Bug

1. 현상과 기대 동작을 분리한다.
2. 가능하면 먼저 재현한다(백엔드: JUnit / Spring 테스트, 프론트: `tests/contract` 또는 Playwright E2E).
3. 증상이 아니라 root cause를 찾는다. 고치려는 함수의 호출부를 모두 확인한다.
4. 수정 전 영향 범위를 확인한다. 계약(API · DTO · 에러 코드)을 바꿔야 고쳐지면 멈추고 사용자에게 알린다.
5. 최소 변경으로 수정한다.
6. 가능하면 regression test를 추가한다.
7. 관련 lint/test/build를 실행한다(루트 `README.md` 「빌드 · 테스트 명령」).
8. 동일 패턴이 다른 위치에도 존재하는지 검색하되, 별도 수정이 필요하면 scope를 임의 확장하지 않는다.
9. 다음을 보고한다.
